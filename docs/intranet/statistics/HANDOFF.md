# 交易统计分析当前交接

> 更新日期：2026-10-16

> 当前阶段：S1、S2、S3 已由用户验收；S4 交易监控大屏已实现，待用户验收。

## 当前实现

- 环境、日期范围、小时下钻日期与交易选择均可驱动统计查询；点击“统计”后通过 API 层刷新数据。
- 指标卡展示总交易量、成功 Y、查无数据 N 与失败 E；Mock 始终满足 `Y + N + E = 总笔数`。
- 图表使用 BaseChart，支持 ECharts Tooltip 和图例切换；覆盖每日状态/总量、平均响应时间、近六个月月度趋势与 24 小时调用情况。
- 每日汇总表展示日期、Y/N/E、总笔数及平均响应时间；空数据和错误交易可演示相应状态。
- `mock.ts` 集中维护环境、交易和统计结果；`api.ts` 是未来内网真实接口的唯一替换点。
- 菜单脚本 `backend/src/main/resources/db/statistics/01_statistics_menu.sql` 只创建开发/验证入口并授权 `super_admin`。

## S2 当前实现

- “维度分析”支持交易、调用方系统、交易-调用方、交易服务四种维度，以及月份范围、环境、交易、调用系统和服务筛选。
- 表格根据维度动态生成身份列，始终展示 Y/N/E、总笔数、成功率和环比变化；支持数值排序、客户端分页和 CSV 导出。
- 表格行点击后高亮对应 Y/N/E 分布柱；图表保留 Tooltip 和图例切换。
- Mock 覆盖正常、空结果、异常、加载及上期为零时“新增”环比状态；演示服务名称不代表真实服务字段来源。

## S3 当前实现

- “排行分析”支持环境、查询月份、调用量/增幅/平均响应时间指标、交易/调用系统维度与正序/倒序 TOP10；每次点击“查询”后由 `getRankingStatistics` 同步刷新图表和明细。
- 横向条形图展示当前选择的 TOP10 指标，第二张图比较可计算增幅记录的本月与上月调用量；点击明细行会高亮对应排行条目。
- 明细含调用量、上月调用量、增幅、平均响应时间和响应样本数，支持 CSV 导出；长名称在表格截断且完整值可由 Tooltip 查看。
- 上月调用量为零时 Mock 不返回增长百分比，页面标识为“新增”，导出标识为“不计算（上月为 0）”。

## S4 当前实现

- 独立“交易监控大屏”由“交易统计分析”页的“打开监控大屏”按钮在新窗口打开，使用静态受保护路由 `/statistics-screen`，不渲染后台侧栏和顶栏；页面提供环境、统计日期、手动刷新及浏览器原生全屏展示，并按常见 16:9 桌面宽度排列。
- 大屏显示总量、Y/N/E、失败率、平均响应时间、活跃调用系统数，以及近七日趋势、Y/N/E 占比、交易调用量 TOP10、24 小时分布、重点交易和统计指标提示。
- 页面每 60 秒重新请求集中 Mock API，并显示最近更新时间和“模拟统计快照 · 非实时监控”标识；未模拟真实实时数据、告警阈值、AI 分析或自动处置。
- `StatisticsScreenSnapshot` 与 `StatisticsScreenFilter` 是内网接入契约；真实 Redis 聚合或已有统计任务接入时只替换 `api.ts`，不新增前端数据源。
- 大屏不创建独立菜单或权限；已执行旧版菜单脚本的开发/验证环境可运行 `backend/src/main/resources/db/statistics/02_statistics_screen_menu_cleanup.sql` 删除旧菜单及授权。

## S1 验收步骤

1. 在开发/验证数据库执行 `backend/src/main/resources/db/statistics/01_statistics_menu.sql` 后重新登录，进入 `/intranet/statistics`。
2. 切换环境、日期范围、小时下钻日期和交易，点击“统计”，确认指标卡、四张图表与每日汇总同步刷新。
3. 在图例中切换 Y/N/E/总笔数，确认 Tooltip 展示正常；确认最近月份显示“本月累计”。
4. 选择“空结果演示交易”和“异常演示交易”，确认空态、错误提示与重试筛选可用。
5. S1、S2、S3 已由用户验收；确认排行页两张图卡在宽桌面下等宽撑满内容区，窄桌面下单列展示。
6. 在 `/intranet/statistics` 右上角点击“打开监控大屏”，确认新窗口打开 `/statistics-screen` 且不包含后台侧栏和顶栏；验证环境、统计日期、手动刷新、全屏、七张指标卡、四张图表、重点交易表和统计提示正常展示。
7. 如已执行过旧版大屏菜单脚本，执行 `backend/src/main/resources/db/statistics/02_statistics_screen_menu_cleanup.sql` 并重新登录，确认侧栏不再显示该菜单。
8. 等待 60 秒或点击“刷新快照”，确认更新时间变化且页面始终标注为模拟快照、非实时监控。
