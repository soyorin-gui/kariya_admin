## 状态切换规则

1. 开始或恢复模块前，先读取本文件、全局 `HANDOFF.md` 以及目标模块的 `PLAN.md`、`HANDOFF.md`。
2. 再核对当前分支、跟踪关系、工作区、近期提交及目标模块真实代码；文档与代码冲突时以代码和 Git 历史为准。
3. 暂停模块时，更新其任务状态、已验证/未验证项、待确认规则和推荐切入点；全局文档只更新状态与索引。
4. 恢复暂停模块时，先向用户汇报核对结果并等待确认，确认前不修改业务代码。
5. 当前活跃模块结束阶段工作时，只更新对应模块文档和本索引；设计、决策、迁移文档仅在事实变化时更新。
